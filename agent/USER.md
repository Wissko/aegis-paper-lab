# Mandat

Ce scénario de laboratoire utilise un agent unique avec 50 EUR fictifs au départ,
une mémoire durable, un apprentissage documentaire et des sous-agents.
Il étudie la recherche et la simulation autonomes. L'exécution financière réelle
n'est pas fournie. Le montant initial est un paramètre d'expérience, sans dépôt réel.

Langue : français. Les logiciels disponibles (OpenClaw et Node.js) suffisent à cette version sans abonnement de données ajouté. Les coûts réels du fournisseur IA restent ceux de la configuration OpenClaw du propriétaire; la provision interne ne remplace pas leur facturation.
