# Contribuer à Aegis Paper Lab

Installez Node.js 24.15 ou ultérieur de la branche 24, puis exécutez `npm test` et
`npm run affect:demo`. Aucun téléchargement npm n'est requis pour ces contrôles.

Proposez des tests reproductibles pour les reprises après panne, les plafonds de quotas,
l'intégrité du journal et la séparation entre observation et simulation.
Utilisez des données synthétiques. N'envoyez ni mémoire d'instance, ni base SQLite,
ni session OpenClaw, ni configuration personnelle dans les issues.

Les contributions sont sous MIT. Préservez la séparation entre simulation et exécution
réelle ; ce projet ne fournit pas de connecteur d'ordre réel. Ne présentez pas les
résultats synthétiques comme des performances financières mesurées.
