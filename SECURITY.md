# Sécurité et confidentialité

Pour un problème de sécurité, utilisez le signalement privé :
https://github.com/Wissko/aegis-paper-lab/security/advisories/new

Ne joignez aucune base SQLite, clé API, session, mémoire ou journal d'instance.
Un exemple synthétique est préférable. Si ce canal n'est pas disponible, demandez
un canal privé via une issue sans exposer de détail sensible.

La démo et les tests sont hors ligne. L'adaptateur Gateway et `npm run smoke` peuvent
contacter des services externes. Une configuration OpenClaw peut engendrer une facture
IA réelle : les quotas et coûts papier ne sont pas un plafond de facturation fournisseur.

Seule cette édition publique est concernée par les signalements. Aucune garantie
de rentabilité, audit indépendant ou engagement de délai de réponse n'est annoncé.
